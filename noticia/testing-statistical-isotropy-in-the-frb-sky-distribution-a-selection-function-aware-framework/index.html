Texto completo

Realizamos um teste de isotropia estatística no Universo usando a distribuição no céu de rajadas rápidas de rádio, com base em uma compilação de eventos de $4.066$ detectados por múltiplas pesquisas. Realizamos um teste de isotropia estatística no Universo usando a distribuição no céu de rajadas rápidas de rádio (FRBs), com base em uma compilação de eventos de $ 4.066 $ detectados por múltiplas pesquisas.

Ambos os estimadores são confrontados com conjuntos hierárquicos de catálogos simulados isotrópicos que propagam as incertezas das funções de seleção de levantamento reconstruídas empiricamente, bem como as flutuações de Poisson das realizações isotrópicas. Quanto aos nossos resultados, descobrimos que o céu FRB bruto é fortemente inconsistente com a isotropia.

O mascaramento galáctico por si só reduz a tensão apenas por um factor de $\sim 3$, enquanto as funções de selecção a reduzem em quase quatro ordens de grandeza, mostrando que a aparente anisotropia é impulsionada pela cobertura do céu altamente não uniforme das pesquisas. Somente quando ambos os efeitos são combinados obtemos que a distribuição observada é totalmente consistente com a isotropia estatística.

Este resultado é corroborado de forma independente pelo estimador de anisotropia absoluta e é estável sob variações dos parâmetros de análise. Descobrimos que a distribuição do céu FRB é consistente com a isotropia estatística, ajudando a confirmar uma das principais previsões do cenário do modelo padrão.

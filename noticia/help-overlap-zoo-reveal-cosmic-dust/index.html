Sua ajuda é inestimável para criar o maior e mais limpo catálogo de pares de galáxias sobrepostas para análise posterior. ” Como voluntário no Overlap Zoo, você verá imagens que os voluntários do projeto Galaxy Zoo identificaram como contendo possíveis galáxias sobrepostas.
